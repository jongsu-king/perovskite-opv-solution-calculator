Solution Preparation Calculator 1.1.0 is the first release with ready-to-run
programs for every desktop platform - no Python needed - and automatic updates.

### New
- **Installers for Windows, macOS and Linux**: a Windows installer and a portable
  zip, macOS disk images for Apple silicon and for Intel, a Debian/Ubuntu `.deb`
  and a Linux archive with a per-user `install.sh`.
- **Automatic updates** (Help → Automatic updates). An installed copy checks GitHub
  at most once a day, downloads the new release for your system, verifies it against
  `SHA256SUMS.txt` and installs it when you close the program. Choose *only tell me*
  or *off* if you prefer. Running from source is never changed.
- **Help menu** with About, *Check for updates…* and a link to the installation guide.
- `--selftest`, `--update` and `--version` command-line options.

### Changed
- An installed copy keeps your material library (`library.json`) in your user
  settings folder, so updates and uninstalls leave it alone. Running from source
  still uses `library.json` next to `solution_calculator.py`.

Calculations are unchanged from 1.0. Full installation guide:
[docs/INSTALL.md](https://github.com/jongsu-king/perovskite-opv-solution-calculator/blob/main/docs/INSTALL.md).
